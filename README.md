# 📅 Paint Schedule — Visual Time Planner

**塗り絵感覚で時間を可視化する、ビジネス＆学習向けスケジュールアプリ**

15分刻み・24時間のグリッドに色を塗って、「今週・今月は何にどれだけ時間を使うか」を一目で把握。
月次・週次の目標欄付きで、計画と実行を一枚にまとめられます。

> 中学時代の「夏休み学習計画表（色塗り式）」を、現代の仕事＆学習用にアップデートしました。
> データは**完全にあなたのブラウザ内のみ**に保存され、外部サーバーには一切送信されません。

## ✨ 機能ハイライト

### ❓ ヘルプ
- ヘッダー右の **？アイコン** から、操作方法・データの保存場所・各エクスポート機能の説明をいつでも確認できる

### 🎯 目標管理
- **月の目標**：その月で達成したい大きな目標を記入
- **週の目標**：今週フォーカスすることを記入
- 目標はPNG / Excel / CSV / JSONエクスポート時にも含まれる

### 📆 3つのビュー
- **日表示**：1日を詳細に見る／編集する
- **週表示**：月〜日の1週間を俯瞰（メインビュー）
- **月表示**：カレンダー形式で1ヶ月を俯瞰、各日の色配分がバーで見える
- グリッドを下にスクロールしても、曜日・日付の見出し行は常に画面上部に固定表示される

### 🎨 ビジュアル
- 15分刻み × 24時間（1日96マス）
- 8色のデフォルトカテゴリ＋色・名前を自由にカスタム
- **カテゴリの表示順をドラッグ&ドロップで自由に並び替え可能**（左パネルの「⠿」ハンドルをドラッグ）
- **選択と確定が分離した操作モデル**：クリック・Shift+クリック・Cmd(Ctrl)+クリック・ドラッグはすべて「仮選択」を作る・伸ばすだけで、その場では色は付かない
  - クリック：1コマを仮選択
  - Shift+クリック：直前の仮選択起点から範囲を伸ばす（連続して使えば、さらに範囲を伸ばせる）
  - Cmd(Mac)/Ctrl(Win)+クリック：不連続な複数コマを1つずつ仮選択に追加／削除（飛び石選択）
  - ドラッグ：ドラッグした範囲をまとめて仮選択
- **確定方法**：左パネルの色見本をクリック（即適用）／仮選択中のコマをダブルクリック（ポップアップを開く）／画面下の確定バーから選ぶ
- **既存の予定の移動**：色が付いた仮選択範囲をもう一度ドラッグすると、形を保ったまま別の時間帯・別の日に移動できる
- 消去：確定バーの「🧽 削除」、またはBackspace／Deleteキー
- 土日・今日の自動ハイライト
- **詳細メモ**：ポップアップ（ダブルクリック／確定バー）を開くと、カテゴリ選択の下に常にメモ入力欄が表示される。「会議」のようなカテゴリ名だけでなく「Aさんと来期予算の打合せ」のような具体的な内容を残せる
- **同じ色で連続して塗ったブロックには、その中央にテキスト表示**（詳細メモがあればメモを優先表示、なければカテゴリ名。幅が狭くて入らない場合は「…」で省略）。メモは移動・コピー＆ペーストにも追従する

### ⌨️ キーボードショートカット
- **Backspace** または **Delete**：仮選択中のコマを消去
- **Cmd/Ctrl + Z**：ひとつ前に戻す（Undo）
- **Cmd/Ctrl + Shift + Z** または **Cmd/Ctrl + Y**：やり直す（Redo）
- **Cmd/Ctrl + C**：仮選択中の範囲をコピー
- **Cmd/Ctrl + X**：仮選択中の範囲を切り取り
- **Cmd/Ctrl + V**：直前に操作したコマを起点に、コピー／切り取りした形をそのまま貼り付け（不連続な形も保ったまま再現される。別の週・日に移動してから貼り付けてもOK）

### 💾 データ管理
- **ブラウザに自動保存**（リロードしても残る）
- **PNG画像出力**（目標＋スケジュール＋集計、グリッド上のメモ表示も含めて一枚に）
- **Excel(.xlsx)出力**（目標／スケジュール／集計／メモ一覧／パレットのシート構成）
- **CSV出力**（目標コメント・メモ付き）
- **JSONバックアップ／インポート**（端末移行・復元用、詳細メモも含む）

## 🛠️ 使い方

### 基本フロー（月の予定が出たら）
1. **月の目標**を記入（その月でやりたい大きなこと）
2. **来月分の各週**に移動して、**週の目標**を記入
3. グリッドのセルを**クリック・Shift+クリック・Cmd/Ctrl+クリック・ドラッグ**で選択（まだ色は付きません）
4. 選んだ状態で、**左パネルの色見本をクリック**（即適用）するか、**ダブルクリック**でポップアップを開いて色を選ぶ
5. 完成したら **📷 PNG出力** で目標つきの画像を保存

### よく使う操作
- **来月の予定を立てる**：日付ピッカーで来月を指定 → 週表示で各週を塗る
- **時間帯を塗る**：塗りたいコマをクリック（1コマ）／Shift+クリック（連続範囲、繰り返し可）／Cmd・Ctrl+クリック（飛び石）／ドラッグで選択 → 左パネルの色見本をクリックして即適用、またはダブルクリックでポップアップを開いて選択・新規作成
- **間違えて塗った範囲を消す**：同じように選択 → 画面下の確定バーの「🧽 削除」、またはBackspace／Deleteキー
- **既存の予定を別の時間にずらす**：色付きの予定を選択した状態で、その範囲をもう一度ドラッグすると、形を保ったまま移動できる
- **カテゴリの色・名前を変える**：左パネルの小さい色ピッカーや名前欄で直接編集（即時反映）
- **データを別端末に移す**：メニュー → JSONバックアップ → 別端末でJSON読み込み
- **集計を見る**：画面下のステータスバーに今期間の合計時間とカテゴリ別時間が常時表示
- **月の振り返り**：月表示にすると各日の色配分が一目でわかる

## 📁 ファイル構成

```
paint-schedule/
├── index.html              # 本体（HTML+CSS+JS全部入り）
├── README.md               # このファイル
└── LICENSE                 # MITライセンス
```

依存ライブラリは CDN から：
- [html2canvas](https://html2canvas.hertzen.com/) - PNG画像出力
- [SheetJS (xlsx)](https://sheetjs.com/) - Excel/CSV出力
- [Inter](https://fonts.google.com/specimen/Inter) / [Noto Sans JP](https://fonts.google.com/noto/specimen/Noto+Sans+JP) - フォント

ビルド不要・依存パッケージのインストール不要。

## 🔧 カスタマイズ

`index.html` 内の `DEFAULT_PALETTE` 配列を編集すれば初期カテゴリを変更できます：

```js

  { color: "#FCA5A5", name: "重要業務A" },
  { color: "#FDBA74", name: "業務B" },
  { color: "#FCD34D", name: "学習・自己投資" },
  // ...
];
```

## 🔒 プライバシー

- データは**あなたのブラウザの localStorage** にのみ保存されます
- 外部サーバーへの送信は一切ありません（CDN からのライブラリ読み込み除く）
- アクセス解析・トラッキングコードなし

## 💡 設計思想

> 中学時代の夏休み学習計画表は、ただの紙とクレヨンだった。
> でも「何の時間に何を割り当てるか」を**目で見て決める**ことで、
> 自然と時間が見え、優先順位がはっきりした。

このアプリは、そのアナログな良さを残しつつ、
- 何度でも塗り直せる
- 集計が自動
- どの端末からも見られる（同じブラウザ内なら）
- 仕事のスケジュール管理にも耐えるデザイン

を目指しました。
